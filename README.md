# GestiónPyme

Panel de administración CRUD para pymes. PHP + MySQL + Bootstrap + Login.

## 🚀 Demo en vivo
https://gestionpyme.nxdigital.es

**Credenciales demo:**
- Email: admin@gestionpyme.com
- Contraseña: password

## 🛠️ Tecnologías
- PHP + PDO
- MySQL
- Bootstrap 5.3
- Sessions (login/logout)

## ✅ Funcionalidades
- CRUD completo de productos
- Categorías dinámicas desde BD
- Login con password_verify()
- Protección de rutas con sessions
- Alertas de éxito en operaciones

## 📦 Instalación local
1. Clona el repo en `htdocs/gestionpyme`
2. Importa la BD desde `/sql/tienda.sql`
3. Edita `config/conexion.php` con tus credenciales
4. Abre `localhost/gestionpyme`
